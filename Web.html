구현 포인트

차트 데이터는 종목별로 보관하고 기본 최대 240개로 제한합니다. 같은 가격의 연속 데이터는 추가하지 않습니다.

설계와 구현 과정

문제

실시간 시세가 계속 들어오면 차트 데이터가 누적되고, 종목 변경 시 이전 연결이 남을 수 있습니다.

해결 방법

종목별 연결·데이터를 분리하고, 기본 최대 240개의 데이터만 보관합니다. 구독 해제 시 소켓도 정리합니다.

Portfolio

소개와 프로젝트를 연결하는 웹사이트

HTML·CSS·JavaScript로 이 포트폴리오를 구성했습니다. 반응형 배치, 고정 헤더, 영상과 마우스 인터랙션을 구현했습니다.

HTMLCSSJavaScriptWebGL
구현 포인트

헤더의 실제 높이를 측정해 섹션 이동에 반영하고, 동작 줄이기와 영상 재생 상태를 제어했습니다.

설계와 구현 과정

문제

고정 헤더가 제목을 가리거나, 보이지 않는 영상이 계속 재생되는 문제가 생길 수 있습니다.

해결 방법

헤더 높이를 ResizeObserver로 반영하고, 화면 표시 여부와 모션 설정에 따라 영상을 제어했습니다. 카드 펼침 상태와 높이도 각각 분리했습니다.

현재 결과

섹션 이동 시 제목 여백이 유지되고, 첫 화면을 벗어나면 영상이 일시정지됩니다. 각 프로젝트의 설명은 다른 카드에 영향을 주지 않고 열립니다.

포트폴리오 구현 노트 읽기

고정 헤더와 섹션 이동

헤더의 실제 높이를 측정하고 ResizeObserver로 변화를 감지합니다. 측정값을 스크롤 여백에 적용해 제목이 헤더 아래에 가려지지 않게 했습니다.

영상과 Liquid 효과

영상은 첫 화면에서만 재생하고, 탭이 숨겨지면 일시정지합니다. 마우스 주변 왜곡은 별도 WebGL 캔버스로 처리하며, 실패하면 원래 영상을 표시합니다.

모션과 입력 방식

동작 줄이기 설정에서는 영상 대신 포스터를 사용합니다. 터치 중심 기기에는 Liquid 효과를 적용하지 않습니다. 본문 바로가기와 키보드 포커스 표시를 제공합니다.

검토 피드백 반영 · 2026.10.27

연속 실무 경력으로 읽힐 수 있는 기간 표기를 제거하고, 프로젝트별 구현·검증·향후 과제를 나눴습니다. GITERVIEW의 기존 백엔드 테스트 3개 통과 기록을 연결했습니다.

의존성과 검증 범위

스타일은 로컬 CSS로 제공하며 Tailwind CDN과 외부 아이콘 폰트를 제거했습니다. Lighthouse 점수나 성능 개선율은 별도 측정 전까지 기재하지 않습니다.
